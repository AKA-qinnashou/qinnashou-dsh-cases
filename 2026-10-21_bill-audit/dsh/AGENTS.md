# 这个文件夹的规矩（给 DSH 看的）

这是一个信用卡账单审计样例文件夹。

- 先读「账单.csv」和「我的卡权益.md」。两份都是虚构示例数据。
- 揪「刷错卡」：换卡能多拿返现/满减的，逐条列（日期、商户、金额、实际用卡、应该用卡、损失估算）。
- 揪「漏领权益」：按月查每张卡的权益（加油满减、视频半价、餐饮返现、贵宾厅等），哪月没用上或用错了。
- 汇总：约少拿多少钱；给排名前 3 的改进建议。
- 算准返现上限和「每月一次」；不确定的标假设。
- 用简体中文、Markdown 表格输出。
- 结果除了展示，还要写进工作区根目录的 `审计报告.md`，三节：刷错卡 / 漏领权益 / 汇总与 Top3 建议（末尾附「关键假设」）。
- 「账单.csv」「我的卡权益.md」只读，不改、不挪、不删。
- 产出文件（报告、摘要、清单、简历等）新建用 write 工具，改用 edit 工具；不要用 bash 的 cat/echo/heredoc/python 写产出文件。搬文件、建目录可以用 bash。
