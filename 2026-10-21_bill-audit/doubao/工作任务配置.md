# 豆包适配版（豆包工作 · 本地电脑）

先说清楚：
- 豆包原来的「创建智能体」，据新闻 2026-07-15 已下线（https://www.sohu.com/a/1045721026_313745 ，第三方报道，非官方页）。所以这里不建智能体。
- 豆包能动你电脑里的文件，靠的是「豆包工作」的「本地电脑」模式（官方：https://www.doubao.com/work/docs/zh-cn/articles/705018132598-plugins.md ）。

## 步骤

1. 打开豆包客户端（或豆包工作客户端），点左侧「新工作任务」。
2. 输入框底部，任务运行环境选「本地电脑」。
3. 底部点「项目」→「通过本地文件夹创建项目」，选放着「账单.csv」和「我的卡权益.md」的文件夹。
   （官方：https://www.doubao.com/work/docs/zh-cn/articles/998584058135-projects.md ，原文：只有运行环境为本地电脑，才能选本地文件夹。）
4. 把下面这段贴进去，回车。

```text
请读取当前目录下的「账单.csv」和「我的卡权益.md」（均为虚构示例数据），帮我做一次信用卡账单审计：
1. 揪出“刷错卡”：哪些消费如果换一张卡支付能拿到返现/满减/权益，逐条列出（日期、商户、金额、实际用卡、应该用卡、损失金额估算）。
2. 揪出“漏领权益”：按月检查每张卡的权益（如加油满200减20每月一次、视频会员半价、餐饮5%返现、贵宾厅次数），哪些月份没用上或用错了。
3. 汇总：6个月内大约少拿了多少钱，给出排名前3的改进建议（例如“餐饮固定刷哪张卡”）。
注意计算要精确，注意返现上限和“每月一次”等限制；不确定的地方请标注假设。用简体中文、Markdown 表格输出。
```

## 可选：做成「工作伙伴」（要团队/企业订阅）

官方：https://www.doubao.com/work/docs/zh-cn/articles/559204524686-workmates.md
入口：插件·技能·伙伴 → 工作伙伴 → + 创建 → + 创建新伙伴 → 个人使用。
详情页「指令」一栏贴上面那段规则即可。
