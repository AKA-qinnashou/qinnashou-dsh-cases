# 豆包适配版（豆包工作 · 本地电脑）

先说清楚：
- 豆包原「创建智能体」，据新闻 2026-07-15 已下线（https://www.sohu.com/a/1045721026_313745 ，第三方报道，非官方页）。这里不建智能体。
- 豆包动本地文件，靠「豆包工作」的「本地电脑」模式（官方：https://www.doubao.com/work/docs/zh-cn/articles/705018132598-plugins.md ）。

## 步骤

1. 打开豆包客户端（或豆包工作客户端），点左侧「新工作任务」。
2. 输入框底部，运行环境选「本地电脑」。
3. 底部「项目」→「通过本地文件夹创建项目」，选「简历对口」（可先放本仓 `demo-简历-原件.md`、`demo-JD-*.md` 试跑）。
   （官方：https://www.doubao.com/work/docs/zh-cn/articles/998584058135-projects.md ，原文：只有运行环境为本地电脑，才能选本地文件夹。）
4. 贴下面这段，回车：

```text
请处理当前工作区里的原简历和各份 JD（pdf/docx/md/txt 都算，文件可能散落）：
1. 不要修改或删除原简历、原 JD 的正文；如需整理，可自行建 raw、tailored、gaps 等目录，把原件归到 raw（或等价位置）；
2. 先通读原简历，列出「已确认经历清单」（公司 / 时段 / 职责与成果原句）。后续改写只能基于这份清单，禁止编造公司、职位、项目、数据、证书；
3. 对每一份 JD：
   - 抽出硬性要求与加分项；
   - 给出匹配说明：已覆盖 / 可改写对齐 / 缺口（缺口不得写进简历正文）；
   - 输出一份对口版简历到 tailored/（文件名含公司与岗位），只调整顺序、小标题和表述，使 JD 关键词更容易被扫到；
   - 对口版里每一条经历必须能回溯到「已确认经历清单」里的原句；
4. 汇总 gaps/待补清单.md：按岗位列出「JD 要但原简历没有」的项，并写一句可执行的补法建议（仍不编造经历）；
5. 不要自动投递、不要打开招聘网站、不要替我点击「立即沟通」或「投递」；
6. 不确定的地方标「待确认」，不要猜。
完成后先展示：各岗匹配摘要 + 待补清单，再给出对口版路径。
```
