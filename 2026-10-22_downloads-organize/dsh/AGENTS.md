# 这个文件夹的规矩（给 DSH 看的）

这是一个要整理的文件夹。

- 只搬，不删。不清回收站，不把文件挪出这个文件夹。
- 按类型建子文件夹：文档/图片/压缩包/安装包/表格/其他，把文件移进去。
- 不改名。
- 拿不准的，列进「待人工确认」，先别动。
- 干完输出新目录树 + 搬移清单（原路径 → 新路径）Markdown 表。
- 核对整理前后文件总数一致。
- `AGENTS.md` 和 `整理报告.md` 留在根目录，不搬、不计入文件总数。
- 新目录树 + 搬移清单 + 「待人工确认」+ 前后文件数，写进根目录 `整理报告.md`。
- 移动用 `mv`（不加 `-f`），不用 `cp` 再删；目标已有同名文件就停下列进「待人工确认」。
- 产出文件（报告、摘要、清单、简历等）新建用 write 工具，改用 edit 工具；不要用 bash 的 cat/echo/heredoc/python 写产出文件。搬文件、建目录可以用 bash。
