# Trae 自定义智能体：照着填

入口：对话框输入 @ → 浮起面板底部「创建智能体」→ 手动创建。
字段来自官方文档 https://docs.trae.cn/ide_agent 。

| 字段 | 填什么 |
|---|---|
| 头像 | 可不填 |
| 名称 | 下载整理（只搬不删） |
| 提示词 | 见下方 |
| 可被其他智能体调用 | 关 |
| 工具 → 内置工具 | 勾「阅读」「文件系统」「终端」；「联网搜索」「预览」不用 |
| 工具 → MCP Server | 不加 |

提示词：

```text
你负责整理我打开的这个文件夹。
硬规矩：
1) 禁止删除、禁止清空回收站、禁止移出本文件夹；
2) 按类型建子文件夹（文档/图片/压缩包/安装包/表格/其他），把文件移进去；
3) 不重命名；
4) 拿不准的列入「待人工确认」，不要擅自处理；
5) 完成后输出新目录树 + 搬移清单（原路径 → 新路径）Markdown 表，并核对整理前后文件总数一致。
分类按扩展名：见同目录上一级的 分类规则.md。
```

另一种用法（不建智能体）：把 `.trae/rules/downloads-organize.md` 整个 `.trae` 文件夹复制到要整理的文件夹根目录，用 Trae 打开这个文件夹即可。规则文件格式依据 https://docs.trae.cn/ide_rules 。

待核：
- 「文件系统」工具是否能「移动」文件（文档写的是增删改查）——待核。勾上「终端」就能用 mv / Move-Item 兜底。
- 规则头部 `alwaysApply: true` 的写法：文档说界面里会自动设置该字段，手写文件是否被同样识别——待核。
