# 这个文件夹的规矩（给 DSH 看的）

这是一个会议纪要 → 今日待办的样例文件夹。

- 处理工作区里今天的会议纪要（录音转写稿、txt、md 都算；文件可能散落、未分类）。
- 如需整理，可自行创建 meetings/raw、meetings/summaries、tasks 等目录；原件归到 raw（或等价位置），不改原件内容。
- 每场会议写一份简洁摘要到 meetings/summaries/（同名 .md）。
- 把所有行动项提取到 tasks/今日待办.md。
- 按【高】【中】【低】分组；每条写：事项 / 负责人 / 截止时间（没提到就写「未提及」）/ 来源会议。
- 优先级：高＝卡住别人或本周硬截止；中＝重要但时间灵活；低＝最好做但无直接依赖。
- 负责人没说清的，单列「待确认」，不要猜。
- 不要修改或删除任何原始纪要/录音转写稿的正文。
- 干完把待办清单直接展示出来。
- 产出文件（报告、摘要、清单、简历等）新建用 write 工具，改用 edit 工具；不要用 bash 的 cat/echo/heredoc/python 写产出文件。搬文件、建目录可以用 bash。
- 原件用 `mv` 归进 `meetings/raw/`，**不改名**、不留副本；摘要文件名和原件同名（如 `raw/demo-input-1.md` → `summaries/demo-input-1.md`）。
